# 🎬 Видео-Переводчик — Telegram-бот

Качественный перевод видео с любого языка на любой, целиком в Telegram.
Пользователь присылает видеофайл → бот распознаёт речь, переводит её на
выбранный язык, озвучивает (TTS) и присылает готовый ролик.

Подписка: **200 ₽/мес**. Аккаунты из paid-programme списка
(`835648334`, `8542930176`) работают без оплаты.

---

## Возможности

- 🌍 Любой → любой язык (whisper распознаёт ~99 языков, TTS озвучивает те,
  для которых есть голоса edge-tts).
- 🎙️ Полная замена дорожки: переведённая речь ложится на оригинальные тайминги.
- 💳 Подписка 200 ₽/мес через Telegram Bot Payments (или демо-режим: перевод
  на карту + кнопка подтверждения).
- 🔓 paid-programme список: внесённые аккаунты освобождены от оплаты.

## Стек

- Python 3.11+, `python-telegram-bot` v21
- STT: **faster-whisper** (модель `base`, VAD-фильтр)
- Перевод: **deep-translator** (Google) или **DeepL** (опц., ключ)
- TTS: **edge-tts** (нейроголоса Microsoft)
- Монтаж: **ffmpeg** (системный бинарь в PATH)
- Персистентность: локальный JSON (`work/store.json`), потокобезопасно

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

Установите **ffmpeg** и добавьте в PATH:
- Windows: `winget install ffmpeg` или скачать с ffmpeg.org
- Ubuntu/Debian: `sudo apt install ffmpeg`
- macOS: `brew install ffmpeg`

Проверка: `ffmpeg -version`, `ffprobe -version`.

### 2. Создайте `.env`

```bash
cp .env.example .env
```

Обязательно укажите `VT_BOT_TOKEN` (от @BotFather).

### 3. Запуск

```bash
python src/main.py
```

Бот поднимется в режиме long-polling. Отправьте ему `/start` из Telegram.

### 4. Настройка платных подписок (до производства)

1. В @BotFather выберите бота → **Payments**.
2. Выберите провайдера (например, **ЮKassa / SberPay**), получите токен.
3. Вставьте его в `VT_PROVIDER_TOKEN`.
4. Перезапустите бота — начнут работать настоящие счета (invoice).

Без токена бот работает в **демо-режиме**: пользователь переводит оплату на
карту (`2202 2061 6956 5376`, задаётся через `VT_PAY_CARD`) и нажимает
«Я оплатил(а)» — это выдаёт 30 дней доступа. Удобно для тестов; в бою деньги
лучше принимать через платёжного провайдера.

## Как устроен пайплайн перевода

1. **ffmpeg** извлекает аудио (16 кГц, моно) и узнаёт длительность ролика.
2. **faster-whisper** распознаёт речь с таймстампами → список `[(start, end, text)]`.
3. **DeepL / Google** переводит текст каждого сегмента на целевой язык.
4. **edge-tts** озвучивает каждый перевод → MP3-фрагменты.
5. **ffmpeg** монтирует: каждый TTS-фрагмент задерживается на момент начала
   исходной фразы (`adelay`), оригинальная дорожка приглушается, обе
   смешиваются (`amix`) и вклеиваются в видео без перекодирования картинки
   (`-c:v copy`).

Качество зависит от исходной записи (шум, перебивки) и выбранной модели
whisper. Для прод-качества увеличьте `VT_WHISPER_MODEL=small` / `medium`.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VT_BOT_TOKEN` | — | Токен бота (обязательно) |
| `VT_PRICE_RUB` | `200` | Цена подписки/мес |
| `VT_CURRENCY` | `RUB` | Валюта |
| `VT_WHITELIST` | `835648334,8542930176` | Аккаунты paid-programme |
| `VT_DURATION_DAYS` | `30` | Дней доступа после оплаты |
| `VT_PROVIDER_TOKEN` | — | Токен платёжного провайдера |
| `VT_PAY_CARD` | `2202 2061 6956 5376` | Карта для переводов (демо-режим) |
| `VT_DISABLE_PAYMENTS` | `0` | Отключить платный шлюз (1) |
| `VT_WHISPER_MODEL` | `base` | Модель распознавания |
| `VT_DEVICE` | `auto` | `cpu`/`cuda` |
| `VT_COMPUTE` | `auto` | Тип вычислений |
| `VT_TTS_VOICE` | `ru-RU-DmitryNeural` | Голос озвучки |
| `VT_DEEPL_KEY` | — | Ключ DeepL (лучшее качество) |
| `VT_POLLING` | `1` | 1 = long-polling, 0 = webhook |
| `VT_WORKDIR` | `./work` | Рабочая папка |

## Лицензия / примечание

Проект — стартовый артефакт бота. Коммерческий запуск требует валидного
платёжного провайдера и хостинга (для whisper + ffmpeg желательна машина с
GPU/большим CPU). Части дообучения моделей не требуют.
